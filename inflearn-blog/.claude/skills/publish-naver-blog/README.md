# publish-naver-blog

네이버 블로그(blog.naver.com)에 글을 자동으로 발행하는 Claude Code 스킬입니다.
Claude in Chrome 확장은 naver.com을 차단하기 때문에, 이 스킬은 별도의 Playwright 크롬을
띄우고 **이미 로그인된 크롬 세션의 쿠키를 복호화해 재사용**합니다. 비밀번호는 입력하지 않습니다.

## 전제조건 (중요)

- **macOS 전용.** 쿠키 복호화가 macOS 키체인의 "Chrome Safe Storage" 키를 사용합니다.
- 크롬에서 **naver.com에 로그인**되어 있어야 하고, **로그인 상태 유지**가 켜져 있어야 합니다.
  (세션 쿠키가 디스크에 남아야 재사용됩니다.)
- `node`, `python3`(+`cryptography` 패키지) 필요. Playwright는 최초 실행 시 설치됩니다.
- 첫 복호화 때 키체인 접근 허용 창이 뜰 수 있어요. "허용"을 누르면 됩니다.

## 쓰는 법

Claude Code에서 "네이버 블로그에 이 글 발행해줘"처럼 말하면 스킬이 트리거됩니다.
자세한 동작은 `SKILL.md`를 보세요. 발행은 되돌리기 어려우니 스킬은 실제 발행 전에
한 번 드라이런(입력만 하고 멈춤)으로 내용을 확인합니다.
