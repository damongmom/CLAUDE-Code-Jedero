# publish-tistory

티스토리(tistory.com)에 글을 자동으로 발행하는 Claude Code 스킬입니다.
티스토리는 Claude in Chrome 확장으로 접근이 되기 때문에, 별도 도구 없이 확장이 제어하는
**사용자의 실제 크롬(로그인된 상태)**을 그대로 몰아서 발행합니다.

## 전제조건

- 확장이 제어하는 크롬에서 **tistory.com에 로그인**되어 있어야 합니다. 비밀번호는 입력하지 않습니다.
- Claude in Chrome 확장이 설치/연결되어 있어야 합니다.

## 쓰는 법

Claude Code에서 "티스토리에 이 글 발행해줘"처럼 말하면 스킬이 트리거됩니다.
글쓰기 화면 진입 → 제목/본문 입력 → 완료 → 공개 발행 순서로 진행합니다.
자세한 절차와 주의사항(네이티브 다이얼로그 등)은 `SKILL.md`를 보세요.
